# Altair フライト動画再生

`index.html` をブラウザで開くと、左下で飛行動画が自動再生され、加速度とオイラー角のダミー値が動画時刻の0.5秒ごとに更新されます。発射前・着地後も小さなノイズが残ります。自動再生は無音です。

mainブランチの `data/index.html`、`style.css`、ロゴを使用しています。HTMLの変更はカメラの `img` を `video` に置き換えること、SDボタンの初期表示を停止にすること、ダミーデータ用スクリプトを読み込むことに限定しています。CSS・項目名・単位・タイトル・フッターはmainと同じです。

カメラボタンの表示・色とSD記録中の黄色は、mainの既存スクリプトの表示を使用します。接続状態欄は動画再生時にmainと同じ「接続中」表示となります。実機との通信は行いません。元からあるステータスメッセージ欄には、リプレイ用の説明・ログを出力しません。動画の再生バーや説明ラベルなどのUIは追加していません。

「カメラ映像を停止」で動画を一時停止し、同じボタンで再開できます。通常はボタン操作不要です。ブラウザに自動再生を制限された場合も、元のカメラボタンで再生できます。右側の「SD記録 停止」「電装動作」はデモ表示で、動画と数値の再生には影響しません。

## ダミー値について

今回生成する値は当初の指定どおり加速度（m/s²）とオイラー角（deg）のみです。加速度はmainの送信形式と同じ小数点以下2桁、オイラー角も2桁で表示します。

以前の版で追加した高度180m・水平移動量の仮定は削除しました。距離・高度の欄はmainのHTML初期値「-」を維持しています。元のHTML動画の数値と合わせるためのデータが提供された場合にのみ、その値を設定してください。

`replay-config.js` で更新間隔、ノイズの振幅、飛行イベント時刻、姿勢キーフレームを調整できます。ノイズは加速度±0.06m/s²、オイラー角±0.15degです。動画時刻から決定するため、一時停止中は数値が止まり、シークで同じ場面に戻ると同じ値になります。

提供された「飛行映像.mp4」は `media/flight.mp4` に無加工で保存しています。35.8秒の映像に合わせ、離陸3秒・姿勢変化14.4秒・着地23.8秒などを目視の推定で設定しています。数値は実測値ではありません。機体のzを機軸、オイラー角はZYX（x=roll、y=pitch、z=yaw）、発射前の相対姿勢を概ね0度としています。

参考の「HTML画面.mp4」は32MiBの転送上限で読み込めていないため、元動画との厳密な画面・数値比較はできていません。画面はmainのコードを基準にしています。

## ローカルで開けない場合

このフォルダで次を実行して `http://localhost:8000` を開いてください。動画のシークに対応したPython標準ライブラリのみの静的サーバーです。

```sh
python serve.py
```

## 検証

```sh
node tests/telemetry.test.cjs
```

動画入りのフォルダはPC・ブラウザ向けです。ESP32用の `data/` は変更していません。
