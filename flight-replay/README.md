# Altair フライトリプレイ

main ブランチの `data/index.html`、`style.css`、ロゴをベースにした、PC・スマートフォン用の動画付き再生ページです。`data/` の実機用画面とは別に配置しています。

## 再生

`flight-replay/index.html` をブラウザで開くと、左下の飛行映像とダミーテレメトリが自動で繰り返し再生されます。インストール、ビルド、実機接続、右側ボタンの操作は不要です。フォルダ一式を保ったまま利用してください。

ローカルファイルで動画再生が制限される場合は、このフォルダで次を実行して `http://localhost:8000` を開いてください。

```sh
python serve.py
```

- 自動再生は無音で開始します。映像の標準コントロールで音声を有効にできます。
- ブラウザ自体が自動再生を禁止している場合のみ、「映像を再生」が表示されます。
- 数値は動画時刻の0.5秒ごとに更新し、次の更新まで保持します。映像自体は通常どおり滑らかに再生します。
- 一時停止・シーク・再生速度変更・リピートに数値が同期します。ノイズも動画時刻から決まるため、同じ場面に戻ると同じ値になります。
- 右側は「ＳＤ記録停止」「電装動作」です。ボタンは画面上のデモ操作で、映像と数値は引き続き再生されます。
- 動画が見つからない・未対応形式の場合は説明とファイル選択を表示します。欠落した映像の代わりに数値だけを進めることはありません。

## 動画とダミーデータ

`media/flight.mp4` は提供された「飛行映像.mp4」をバイト単位でそのままコピーしています。切り抜き・回転・速度変更・再圧縮はしていません。映像全体が収まる `object-fit: contain` で表示します。

映像は35.8秒です。目視で見える約14秒台の姿勢変化と約24秒以降の静止に合わせ、次の演出用タイムラインを設定しました。離陸・燃焼終了・頂点・パラシュート展開は映像からの推定です。動画だけでは実際の加速度・姿勢・高度を特定できないため、**すべてのセンサー値はダミー**です。高度180mや水平移動距離も仮値です。

| イベント | 動画の先頭からの秒数 |
| --- | ---: |
| 離陸（推定） | 3.0 |
| 燃焼終了（推定） | 4.3 |
| 頂点（推定） | 12.8 |
| 姿勢変化・パラシュート降下（推定） | 14.4 |
| 着地・静止 | 23.8 |

加速度は機体座標で z を機軸とする、重力を含む加速度計出力のイメージです。発射前は約1G、燃焼中は大きな加速度、慣性上昇はほぼ0G、姿勢変化時と着地時に過渡的な変化を与えています。静止後は姿勢に合わせて重力を各軸に分解します。

オイラー角は ZYX、x=roll、y=pitch、z=yaw、単位deg、表示範囲[-180, 180)です。発射前の機体を概ね0度とし、カメラの取り付け方向は相対姿勢の基準に含めていません。角度が180度をまたぐ際の符号反転は表現上の折り返しです。

発射前・着地後も、加速度・オイラー角・位置・高度に軸ごとに異なる小さな計測ノイズを加えています。着地時の衝撃が収まった後も揺らぎが続きます。ノイズ振幅は加速度±0.06m/s²、角度±0.15deg、各水平位置±0.03m、高度±0.08mです（飛行の変化・振動とは別に加算）。地上の高度は0mを中心に揺らぐため、わずかに負の値も表示されます。distはノイズを含むx_dist・y_distから算出します。

更新間隔は `replay-config.js` の `telemetryInterval`（秒）、ノイズの大きさは `sensorNoise` で調整できます。再生速度を変えた場合も、更新間隔は動画の時間を基準にします。

`replay-config.js` の `timeline`、`attitude`（秒・roll・pitch・yawの配列）、高度・移動量を編集して調整できます。動画を差し替えた場合は、同じ設定が適合するとは限らないため時刻と姿勢を調整してください。

参考用「HTML画面.mp4」は32MiBの転送上限を超えて読み込めなかったため、画面構成はmainブランチのHTMLを参照しました。

## 構成と検証

- `index.html` / `style.css`: 既存デザインを引き継いだ画面
- `script.js`: 動画の現在時刻を基準とする描画・デモ操作
- `telemetry.js`: 時刻からダミー値を算出する関数
- `replay-config.js`: 動画パス・飛行イベント・姿勢キーフレーム
- `media/flight.mp4`: 元の飛行映像（変更なし）
- `serve.py`: シークに必要なHTTP Rangeに対応したローカルサーバー（Python標準ライブラリのみ）

```sh
node --test tests/telemetry.test.cjs
```

Chromiumで発射前・着地後の揺らぎ、同じ0.5秒区間内での値の保持、通常再生時の約2Hzの数値更新、自動再生、一時停止、シークによる数値一致、両ボタン操作後の再生継続、リピート、390px・768px幅の表示、動画欠落時の案内とファイル選択による復帰を確認済みです。ローカルHTTPサーバーで検証しました。

動画が約7.7MBあるため、このフォルダをESP32のLittleFSへ書き込む用途は想定していません。PCのブラウザまたは静的Webサーバーで利用してください。
